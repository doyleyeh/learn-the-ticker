## Experiments and repair record

The pinned CLI's `sandbox --help` and reviewed `rust-v0.158.0-alpha.2.1` source show `codex sandbox -- COMMAND` on Linux; older `sandbox linux` examples do not apply. A strict-config standalone experiment also failed, while the explicit read-only override worked. The actual app-server policy still needs separate verification; no production guard was changed to accommodate this experiment.

The first small private D-Bus/GNOME keyring experiment passed synthetic storage/retrieval, a nonempty random password and a private keyring file without the plaintext canary. The repeatable helper then encountered three failed executions: a private bus-address/path check, followed by two failures at the TCP sandbox step (the latter run added stage-specific reporting). Diagnosis: long Unix socket paths/escaped bus addresses needed bounded path handling, and the network test created its socket outside its error handler. The sandbox can deny socket creation itself before connection. The repair shortens the owned path, validates the decoded private address and tests socket creation inside the denied-operation block. It does not relax the sandbox or accept arbitrary errors. Further execution is justified by these concrete diagnoses; no external blocker is declared from those helper defects.

Before the network repair, the complete keyring slice already passed actual encrypted restart persistence, Codex logout removing only its synthetic profile item, the other synthetic profile remaining intact, unavailable-bus rejection and absence of auth.json. The file probe read its controlled canary and could not overwrite it. A subsequent run exposed bootstrap Python 3.10's missing asyncio UDP socket APIs; this helper now explicitly requires Python 3.11+ and runs under the new Python 3.12.15 application environment. The final actual matrix passed all four IPv4/IPv6 TCP/UDP denial cases against listeners that each first observed a successful host control. No listener observed sandbox traffic. The pinned binary was rehashed; all owned daemons and temporary workspaces were closed.
