- The [price-history reference](https://ranaroussi.github.io/yfinance/reference/yfinance.price_history.html) supports a five-year period and action retrieval, with automatic adjustment enabled by default. A future adapter must deliberately preserve and label price/adjustment semantics, time zones, currency and missing data. [Price repair](https://ranaroussi.github.io/yfinance/advanced/price_repair.html) can reconstruct observations; it must not silently turn inferred/repaired data into original reported values.

[Taiwan terms](https://legal.yahoo.com/tw/zh-hant/yahoo/terms/otos/index.html) describe a personal API/software license conditional on applicable terms. [Developer API terms](https://legal.yahoo.com/us/en/yahoo/terms/product-atos/apiforydn/index.html) also require API-specific documents. These excerpts do not establish authorization for the Finance endpoints yfinance uses. Direct legal-page retrieval returned HTTP 999; no full-page review or definitive regional legal conclusion is claimed.

No Yahoo market-data endpoint was queried, package installed, rule widened or restriction bypassed. Source attribution and a noncommercial local app are relevant design constraints, but they do not alone answer the outstanding permissions. ## Concrete permission path

Prefer an API/dataset whose published terms expressly cover the intended operations. If those terms are unclear, the following inquiry is ready for the user to send to the provider; no message has been sent:

> I am developing a free, open-source Windows application for individual, noncommercial financial learning. Each user runs it locally; there is no hosted data feed or bundled market dataset. May each installation use your documented API for historical daily prices, dividends/splits, company statistics, news metadata and available analyst estimates? Please identify the applicable endpoints, plan and terms, and whether they permit local display/cache, retaining cited snapshots, personal backup/restore and export, and sending a bounded selection to the user's chosen cloud AI provider for explanations. Can permitted uses be enabled separately where another operation is restricted? What attribution, retention limits, rate limits and exchange/publisher conditions apply?

An existing plan with explicit applicable permissions may be enough; a custom agreement is not automatically required. Reuse rights must cover the actual operation, not hypothetical public redistribution. News metadata, full articles/images, analyst material and numerical data may have different conditions. A user checkbox records consent but cannot create a provider entitlement. Cloud-model use needs both user consent and source-compatible use; display-only content must not automatically enter factual prompts or backups.
