## Implemented boundary

Sources separately requests local processing and storage/backup permission. Saving reparses original file bytes, or retrieves a permitted public URL again, and requires the displayed fingerprint. Changed content, missing permission, revoked rights and exhausted capacity cannot write. The authenticated metadata list excludes bytes; reopening uses original bytes in the bounded parser queue, validates the extraction/current rights and preserves original dates, locators and unverified state. It works offline and never creates facts/chart values or grants provider transmission. Cancellation closes owned parsing. A lost save response truthfully advises checking the refreshed retained list before retrying.

Connections includes document count and byte totals in archive validation. Existing portable archive integrity, rights, atomic restore and nonempty-target checks remain in force.
