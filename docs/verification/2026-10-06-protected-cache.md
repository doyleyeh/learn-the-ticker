# Protected disposable cache

Date: 2026-10-06 (Asia/Taipei). Scope: M9-T01e/P-043/P-044, DEC-059. M9 and public Windows v1 remain incomplete.

## Behavior and accounting

The default 10 GB is 10,000,000,000 bytes of disposable stored JSON payload. Database-side lengths count records, job requests/results and normalized events. Protected saved/import/learning work is measured separately and may exceed that amount. These figures do not promise total physical database/disk usage, immediate file shrinking or archive capacity.

Protected graph roots include bookmarks, conversations, comparisons, reports, retained originals, learning explanations and their scoped job history. Reference closure preserves all original bundles, including older numerical-context versions and the current page required by conversation scope. Disposable connected groups retain reference integrity and are removed oldest first only above budget. Queued/running jobs defer all removal. Unknown/missing references fail closed. Metadata projections do not return financial bodies, attachment bytes or complete job results to the planner; PostgreSQL also projects only conversation reference IDs.

Every app-owned PostgreSQL session transaction takes a shared advisory lock before its row/table locks; cleanup takes it exclusively. Bookmark and term admission now recheck originals inside that transaction. Event/job/record deletion commits atomically in batches. Startup and five-minute cleanup run on the service event loop, ordered with synchronous terminal publication. Connections provides read-only accounting and an explicit authenticated offline cleanup action. No dependency, schema/archive revision, new source permission or provider invocation.
