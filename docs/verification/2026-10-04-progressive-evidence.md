# Progressive admitted sections — 2026-10-04

M4-T02b implements [DEC-032](../../DECISIONS.md#dec-032-preserve-admitted-sections-as-incomplete-research-versions). It does not close optional source review, market-data/return acceptance or the M4 milestone.

## Behavior and review

Independently retrieved issuer history can appear before inference, and the first independently supported narrative section can appear while source verification continues. At most two intermediate versions are created per run. Each has original citations and an immutable `section_checkpoint` marker separate from data availability. It contains no notes or candidate sources and reuses identity, source-rights, numeric and literal-support validation. Unsupported model output never streams as facts.

Bundle, job reference and progress event are one transaction. Final research uses another immutable version; only final publication advances the current asset/conversation. Failure/cancellation preserves the last checked section and earlier completed asset. Restart/restore interrupts the job without replay. Earlier section citations/bookmarks remain usable and exports disclose incomplete research. Checkpoints cannot become current assets or fresh-cache substitutes. Enabling manual review blocks subsequent automatic admission; previously admitted immutable evidence remains historical. No dependency, SQL/archive revision, provider capability, source policy or paid service changed. Older binaries remain unqualified rollback targets.
